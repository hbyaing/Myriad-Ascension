# 御剑化虹

归元、天阙灵剑获得化虹，不占剑技槽。需要已学御剑凌霄诀并满足当前御剑、遁虚的驾驭及熟练度条件。

保持向前加速，实际位移速度达到当前正常高速目标（含凌空等级、服务器速度倍率及巡航比例）的 90%，稳定 20 tick 后聚虹。聚虹 6 tick，人剑淡出；随后用 8 tick 将正常目标速度平滑提升到两倍。倍率只应用一次，不写回普通巡航目标；不能通过贴墙、未加载区块或原地按键积累。

化虹与遁虚正交。化虹不授予穿墙、无敌、额外伤害，也不消除碰撞体。遁虚仍使用原来的资格、进入费用、维持费用、禁穿方块、实体与区块加载检查。化虹期间不触发惊鸿滚转冲刺或御剑冲撞，防止额外加速和伤害叠加。

松开加速、制动、灵力不足、期望方向与飞行方向相差超过 55 度（俯仰 45 度）、两 tick 前瞻路径受阻或未就绪时退虹。速度加成立即停止，已有动量按原有减速机制消退；身体/灵剑在 8 tick 内恢复，退出后另有 20 tick 的重新聚虹间隔。实际移动仍逐段扫描，最终碰撞检查不会由视觉或前瞻代替。

入虹收取最大灵力 1%，聚虹/化虹期间维持每秒最大灵力 2%（沿用装备维持消耗修正）；该费用替代普通御剑维持费，遁虚费用独立追加。三段切换只发送一次动作栏提示。

第三人称采用程序几何和 GLSL，默认使用加粗提亮的虹核流星：白色轴向亮芯、虹色伴流和出生位置固定的短余芒。尾迹按固定 tick 采样、距离重采样和年龄淡出。普通御剑尾迹保持独立参数；模型与拖尾共用精确剑尾变换，并在渲染帧插值贴合。第一人称不绘制自身世界尾迹和贴脸光核，保留中央视野及轻微边缘光。关闭御剑特效时保留人物/剑可见。

背包 → 设置 → 御剑飞行 → 化虹皮肤提供八种外观：虹核流星、燃尾流星、贯空长虹、开放流羽、红黑离烟、赤焰撕裂、扇形流霞、蓝白虹流。复用金墨自绘按钮、选中态和说明提示；不改变背包独立缩放。选择保存到客户端 `FlyingSwordConfig.HUAHONG_SKIN`，登录、重生和修改后发送 C2S 消息 96，协议版本为 108。服务端仅更新发送者的偏好和飞剑同步元数据；非法 ID 回退虹核流星。各客户端从飞剑元数据选择外观，切换时清理该飞剑的旧皮肤历史，不改变速度、灵力、碰撞或权限。后续枚举顺序须保持稳定，不能重排已有网络 ID。

八种皮肤使用不同的流星、火舌、单束、开放流羽、烟团、撕裂火焰、扇流及圆形截面结构。红黑离烟保留暗色 alpha 吸收，Bloom 通道排除暗烟；其他材质分别限制泛光。蓝白虹流为本项目独立三维几何适配，未复制许可未确认的 V13 参考代码，也不等于 V13 体积算法的精确移植。

御剑与境界遁光共享非阻塞地形就绪检查，每位飞行玩家最多持有三个短时前瞻区块票据；未就绪时限制移动，不能穿越未加载地形。碰撞扫描先跳过确认空旷的粗段，仅在可疑段细扫。灵脉洞壁扫描及连通性搜索分批执行，写入前重新检查目标方块，避免长途新区块生成将整次扫描塞进一个 tick。

复用普通深度绘制、光影后绘制和深度约束选择性 Bloom，不新增实体或模型资源。服务端维护阶段、灵力和移动；实体同步元数据提供追踪时状态快照。退出世界或卸载效果时清理客户端历史。

验证入口：`gradlew verifyFull --offline`；独立客户端 `-PmyriadCapture -PmyriadUiOnly -PhuahongCapture -PhuahongSkins runClient`，测试专用指针保护随该 source set 加载。光影专项额外启用 `-PmyriadExternalShaders` 并在独立 QA 目录选择光影。剑尾专项使用 `-PswordTailCapture -PswordTailOutput=reports/sword-tail-check`。测试源和指针保护不进入正式包。

客户端画面测试可使用 0.1 倍服务器速度来保持可控视场；正常倍率及实际两倍速度由服务端 GameTest 独立验证，不能将降速截图作为全速流畅性证据。
