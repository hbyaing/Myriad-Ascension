# 御剑化虹

归元、天阙灵剑获得化虹，不占剑技槽。需要已学御剑凌霄诀并满足当前御剑、遁虚的驾驭及熟练度条件。

保持向前加速，实际位移速度达到当前正常高速目标（含凌空等级、服务器速度倍率及巡航比例）的 90%，稳定 20 tick 后聚虹。聚虹 6 tick，人剑淡出；随后用 8 tick 将正常目标速度平滑提升到两倍。倍率只应用一次，不写回普通巡航目标；不能通过贴墙、未加载区块或原地按键积累。

化虹与遁虚正交。化虹不授予穿墙、无敌、额外伤害，也不消除碰撞体。遁虚仍使用原来的资格、进入费用、维持费用、禁穿方块、实体与区块加载检查。化虹期间不触发惊鸿滚转冲刺或御剑冲撞，防止额外加速和伤害叠加。

松开加速、制动、灵力不足、期望方向与飞行方向相差超过 55 度（俯仰 45 度）、两 tick 前瞻路径受阻或未就绪时退虹。速度加成立即停止，已有动量按原有减速机制消退；身体/灵剑在 8 tick 内恢复，退出后另有 20 tick 的重新聚虹间隔。实际移动仍逐段扫描，最终碰撞检查不会由视觉或前瞻代替。

入虹收取最大灵力 1%，聚虹/化虹期间维持每秒最大灵力 2%（沿用装备维持消耗修正）；该费用替代普通御剑维持费，遁虚费用独立追加。三段切换只发送一次动作栏提示。

第三人称采用程序几何和 GLSL：细亮头、连续白芯和青金薄晕、真实世界历史长虹。归元偏青，天阙偏金。聚虹采用向轴线收束的开放光丝，起点短弧保留在出生位置；尾迹按固定 tick 采样、距离重采样和年龄淡出。普通御剑尾迹保持独立参数。第一人称不绘制自身世界尾迹和贴脸光核，保留中央视野及轻微边缘光。关闭御剑特效时保留人物/剑可见。

复用普通深度绘制、光影后绘制和深度约束选择性 Bloom，不新增实体或模型资源。服务端维护阶段、灵力和移动；实体同步元数据提供追踪时状态快照。退出世界或卸载效果时清理客户端历史。

验证入口：`gradlew verifyFull --offline`；独立客户端 `-PmyriadCapture -PmyriadUiOnly -PhuahongCapture runClient`，测试专用指针保护随该 source set 加载。光影专项额外启用 `-PtalismanUserStack -PmyriadExternalShaders`。测试源和指针保护不进入正式包。

客户端画面测试可使用 0.1 倍服务器速度来保持可控视场；正常倍率及实际两倍速度由服务端 GameTest 独立验证，不能将降速截图作为全速流畅性证据。
