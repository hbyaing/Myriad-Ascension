# 高速冷区块飞行：地表投影预算修正（2026-11-01）

承接 `d583ebe` 的特效修正。用户明确选择保持可见距离 32、模拟距离 32；本轮不降低这两项设置。筋斗云保持回退，已交付的特效几何、材质、横向尺度与剑柄裁剪不变。

## 已确认的服务器问题

JFR 在冷路线的长服务器刻中记录到 `NoiseBasedChunkGenerator.getBaseHeight → SpiritPlantRegions.surfaceBiome → ConnectedBiomeRegion.step → SpiritPlantRegions.advance`。原有 2 ms 截止时间只能在两个采样之间检查，不能中断一次昂贵的高度计算，因此不是硬上限。

标准原版噪声生成器及明确列出的原版生物群系源现在使用一个低并发、有限队列的后台采样器。工作只保留生成器、RandomState、固定高度范围和生物群系查询器，不保留 ServerLevel、ChunkSource、实时高度图或世界随机源，不请求区块，也不在工作线程放置方块。

每个维度最多一个待完成批次，每批最多 16 个坐标，缓存最多 256 项；服务器轮询未完成结果时立即返回。结果未就绪时不弹出搜索队首，不分配新区域，也不改变遍历顺序。自定义生成器保留原来的同步兼容路径；后台异常记录警告并回退。NBT 格式、配额、最终放置和玩家飞行速度不变。

## 继续定位画面长帧

追加的游戏阶段、模型提交、原生绘制及线程 CPU 时间记录均只存在于测试源集。长帧曾落在实体渲染阶段，且存在墙钟远大于当前渲染线程 CPU 时间的样本。没有据此认定是某个驱动、GPU 编译或 Embeddium 本体缺陷。

尝试的模型与几何预热没有稳定改善，已经撤回。进一步的 `height-after32-auto10-cpu` 在第 33 刻实体阶段记录到 1303.962 ms 墙钟、62.5 ms 当前线程 CPU 时间；JFR 明确记录 `DunxuTransparency.wrap` 的 LambdaMetafactory、透明材质转换及相关类首次加载，不再笼统归因于 GPU 编译。

透明缓冲包装改为明确的 AlphaSource 类，材质缓存直接查询与写入，去掉这里的首次 Lambda 绑定；在既有客户端初始化中加载该载体。`named-wrapper` 同样使用自动 10 个网格线程，完整 640 刻无错误，最大相邻帧间隔 83.802 ms、超过 50 ms 两次；此前自动 10 线程样本为 1553.162 ms。不同运行的首次加载时机存在波动，这不是严格的全场景改善率。其剩余首帧中 JFR 又记录到 HuahongHeadBridge 首次定义约 41 ms；最终代码在客户端初始化时链接该纯计算类，不创建虚构历史、模型、几何或 GPU 工作。

网格线程数对照曾出现 2 线程样本最大间隔 46.308 ms，但后加的测量外截图和渲染统计确认航线后段地形网格为空。该样本不能作为地形正常加载的通过证据，也不能据此自动调整实际实例的 Embeddium 设置。玩家追踪区段在真实飞行中正常随位置推进，排除了始终停留在出生点这一具体猜测。

测量结束后的一张场景截图用于核对地形可见性，不参与帧间隔计时；测量过程中仍没有截图或 GPU 回读。后续采样保留逐秒地形探针，明确区分稳定的画面提交与完整地形跟随。

网上检索参考沿用前一份 [特效与模拟距离报告](FLIGHT_SUBMISSION_STATE_20261101.md) 的一手来源。C2ME 是 Fabric 工程，不作为本 Forge 实例的直接安装方案；没有预生成用户世界，没有修改第三方 Mod。

本修正移除了一个实际服务器主线程热点，尚不构成“地形结构加载卡顿全部根治”的结论。

## 最终复测中仍未通过的项目

`final-cold32` 重复出现 1340.920 ms 最大帧间隔，否定了将前一轮 83.802 ms 当作稳定改善的判断。该次实体阶段的 JFR 指向 Embeddium 顶点消费者诊断注册表首次加载的 fastutil 集合类，化虹阶段还包含烟雾数据载体的首次定义。最终代码在已有可选 API 初始化中链接该无 GL 诊断注册表，并在客户端初始化中链接 Row、Birth、Cloud、Smoke 数据类；没有运行模拟模型或虚构特效，也没有修改第三方 JAR。

`linked-carriers32` 保持自动 10 个网格线程、32/32、完成 640 刻且无错误。上述已定位类的等待移出了首个飞行提交，但整段最大帧间隔仍为 645.478 ms、超过 50 ms 五次。最长游戏循环间隙还包含原版聊天状态与按键文本首次加载；另有化虹绘制阶段 264.592 ms 墙钟 / 46.875 ms 当前线程 CPU 时间，不能归因于同一个已修正的类加载点。服务器区域 advance 累计 53.778 ms、最大 0.348 ms；这项改善在追加冷路线中保持。

初始可见地形网格约 150 MB，后段归零；地形没有跟上高速路线仍是未解决项。报告保留失败结果，不把空场景流畅、某一轮短帧、初始化链接或服务器热点移除当作全部通过。
