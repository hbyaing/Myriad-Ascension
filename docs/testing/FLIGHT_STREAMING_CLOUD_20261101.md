# 高速飞行：筋斗云连续性与冷区块性能

> 后续用户要求筋斗云定向回退，当前 Cloud 实现见 `CLOUD_ROLLBACK_20261101.md`；本文保留当时的实验记录，不代表回退后仍启用这些 Cloud 修改。

基线为 `f214a989bfefdd11e89057a0e221b7b636b6ce22`。普通御剑的剑柄边界修复已在该提交交付，见 `ORDINARY_SWORD_POMMEL_20261101.md`。本轮继续处理化虹加载卡顿，并按用户补充要求处理筋斗云高速抽动。

## 修复依据

- 筋斗云旧版将世界时间同时用于历史采样、寿命和材质；真实神通实飞中出现 `296.740 → 39.080` tick 的自然校时回退，随后清空历史。这次事件发生在预载后的早期；另一个 Solas 常规飞行窗口在 clock245 自然回拨约 2.62tick，并出现尾迹整块缩没再重现。二者单独标记，不能用早期事件解释之后所有高速材质闪动。
- 旧云尾的 Worley 材质绑定绝对世界坐标，头部细节流动还随飞行距离加速。高速下，即使云锚点稳定，也会快速扫描不同噪声单元。候选使用云局部材质场、显式低速时间流动，并保留历史路径、云团几何、密度、颜色和光照公式。停移时冻结历史朝向，材质动画继续。
- 新增世界内独立客户端时钟，供云历史、材质、远端可见 TTL 共用；服务器校时不再倒转这条时钟。切换世界清空，暂停冻结。
- 云的原版与 Solas 后绘制路径明确使用同一 atlas 线性过滤。旧 Solas 没有实际过滤参数探针，不将其写成已证实的 NEAREST 原因。
- 真实前视高速录像还暴露了人物整帧消失。原版裁剪使用当前 tick 包围盒，镜头与云使用 `getPosition(partial)`；模型入口又使用 `xOld`。仅对本地开启筋斗云的玩家，以实际显示位置移动裁剪盒，并对模型矩阵补 `xo−xOld` 插值差。保留原有范围、`.5m` 裁剪余量和 noCulling 策略，不写玩家、镜头或网络坐标。
- 首次 Solas 候选仍有 38/355 帧人物未绘制，未将其计作通过。另查出 `LevelRenderer` 在 frustum 判断后、提交人物前还有 `entity.blockPosition() → isChunkCompiled` 地形网格门槛，Embeddium 映射为当前 section 的 `isSectionBuilt`。项目原有 `FlightChunkVisibilityMixin` 已对本地御剑处理，漏掉筋斗云；本轮把同一有限分支扩到本地 active 云的玩家当前位置，人物仍经过真实 frustum/距离判断。

## 加载与分配优化

32 视距实验中的最长帧不能仅由区块上传解释。基线无光影最长帧约 56.67ms，Solas 约 102.87ms；这些峰附近还采样到化虹过渡阶段的透明剑模型，而并非仅区块网格。各计时跨度包含嵌套关系，工作线程并行，不能相加当作帧 CPU。

- 炼丹炉标脏和炼器台无关邻域筛查改用可复用坐标和 `getChunkNow` 的现有 LevelChunk。旧 `hasChunkAt` 不能保证 FULL future 已完成，旧炼器台筛查实际进入过同步 chunk future 路径。真实存在的炼器台仍使用原来的完整结构验证，保留跨区块组装与更新时序。
- 化虹 SMOKE 只建立实际会查询的 32m 输运窗口，并保留完整滤波支撑和原有头部固定采样网格；实际可见/出生区域最多约 24.05m。DENSE 的核心 sprite 不使用路径，跳过原本未被查询的完整路径构造。其他皮肤使用完整路径。
- 透明剑模型对已核实的 NEW_ENTITY / ModelVertex 使用可选的 Embeddium packed quad 提交，复用编码临时内存；保留普通 VertexConsumer 接口。此处恢复的是逐 quad 打包提交，不声称恢复整模型 intrinsic。无可选 API 的已知 NEW_ENTITY 输入使用同一保真解析器逐顶点提交；未知格式或非 32-int quad 使用原默认路径。
- 首个 Solas 缓冲区对照实际拦住法线差异（旧值 0、新值 129）：Oculus 在逐顶点/endVertex 阶段补充法线、切线等，packed push 会绕过这条语义。最终按实际目标的 `iris$extending()` 保留全部逐顶点钩子，同时复用向量、直接解析已有 int[]，省掉默认临时数组、Buffer 视图与每顶点 Vector；逐项调用同一 target，保持原来的返回值忽略、颜色量化、光照和法线语义。Solas 此项为缓存解析收益，不称为 packed 收益。
- 第一组冷路线候选未获得整体帧时改善，并在无光影首次进入化虹透明阶段出现约 74.18ms 峰。JFR 明确命中新增 packed helper 的惰性类初始化，主区块工作不足以解释该峰。最终版本在首次客户端 tick 提前解析可选 API、内部类型和小型临时缓冲，后续另用未跑过的冷路线副本复验；中间回归数据保留。

飞行速度、32 视距/32 模拟距离以及区块上传预算均未调低。异步生成新地形的成本仍需按实际冷路线数据判断，预载场景不作为加载性能验收。

## 验证记录

本机原始证据分别在 `reports/jindou-repro-20261101`、`reports/jindou-motion-20261101` 和 `reports/cold-flight-32-20261101`。筋斗云测试通过真实 `DivineArtLogic.release` 激活，再使用独立客户端的前进、疾跑和视角输入；录制过程中不覆盖坐标、速度、插值快照或服务端轨迹。初始传送和预载均在录制阶段之前。云录像仅用于画面验收，不当作冷区块性能数据。

冷路线使用同一完成静态热身的正常地形存档快照，分别复制基线/候选与无光影/Solas 世界。前段已有区块，后续路线的区块头不存在；不提前生成未来路线。测试保持 2560×1440、32/32、8GiB、20 逻辑处理器和实际 Embeddium 设置，关闭截图与网格收集，记录 600 tick 前飞和 40 tick 刹车，使用 JFR 与实际主线程工作跨度交叉检查。

最终无光影云候选为 `candidate-native-final`：818 张连续源帧，最高约 `10.792m/tick`，无时间回拨或历史清空，全部帧真实 Player Pre/Post 均触发。只读探针观察到 203 帧“当前 tick 包围盒在 frustum 外、显示插值包围盒在内”，人物仍完整绘制；本轮原始 Embeddium section-ready 值全部为 true。实际 `xo−xOld` 差为 0，不能把该轮称为非零模型平移补偿的实机复现。

最终 Solas 为 `candidate-solas-final`：385 张连续源帧，Player Pre/Post 385/385。原始 Embeddium section-ready 为 false 的 11 帧，人物仍全部完成绘制，真实相邻画面确认没有消失；真实 frustum/距离判断仍保留。独立逐页检查直行、5°/tick 转弯、后视、松键但保留神通、老尾老化回收和静止窗口的全部相邻帧，两种渲染路径均未再见旧版整段尾迹缩没后重现。视频均为目录中的 `continuous-vfr.mp4`，保留所有实际源帧与原时戳，无插帧或曝光调整。

验收范围为这条真实输入路线，不扩大为所有帧率、全地形、反复开关、非零插值差或真实传送已完成实机覆盖；传送/暂停/40m-tick 连续高速另有实际 Track 与纯时钟检查。录制采用已预载平坦世界，加载性能由下一项独立验证。

最后缓存解析版的独立 checks-only 客户端对照：无光影 960/960 case 实际命中 packed；Solas 在 11 元素 Iris 扩展格式上 960/960 使用逐顶点钩子，与原算法逐非 padding 属性字节一致，含 entity、mid-texture 与 tangent。Solas 局部 quad 探针分配从 528 降到 192 Java 字节，编码约 2,964→1,560ns/quad；这些是局部探针，不能当作整帧提升。另在实际不含 Embeddium/Oculus 的 JDK17 运行 classpath 验证了 20 case / 2,800 属性字节；这是缓冲路径验证，不是完整无可选 Mod 客户端启动验收。

生产路径窗口通过 19,358 项可见区域与出生节点对照，最大位置/朝向差为 0。80 次构造探针分配从 85,143,040 降到 17,180,160 字节，约 4.956 倍；此为构造器探针，不当作整体帧率提升。原先无光影 before-begin 微基准未命中 packed，已作废；最终无光影在正确绑定后局部 packed quad 编码达到 0 Java 分配字节/quad，仍以独立冷路线数据判断实际性能。

最终冷路线编译前已同步远程 `41d6d2f`、`45a964c` 的识海更新，未覆盖协作者代码。其相关类/资源不在本次主世界飞行场景使用；云组件、shader、纹理与上述最终录像逐项核对。编译中止或失败诊断轮保留并明确排除，冷路线使用未经历中止飞行的 pristine 存档副本。

## 最终冷路线结果

最终目录为 `candidate-native-legacy-final` 与 `candidate-solas-legacy-final`，均完成 600 tick 前飞加 40 tick 刹车。基线与最终采用相同 runTick HEAD 场景时钟选取飞行窗口；RETURN 时钟会误纳最后一个热身帧，未混用该口径。数值单位为 ms。

| 环境 | p50 基线→最终 | p95 基线→最终 | p99 基线→最终 | 最慢帧基线→最终 |
| --- | ---: | ---: | ---: | ---: |
| 无光影 | 5.8436→5.8419 | 8.0739→7.5560 | 11.5985→12.5259 | 56.6688→54.2499 |
| Solas | 13.5977→13.5897 | 19.3388→19.1636 | 24.9909→24.8242 | 102.8702→73.4903 |

Solas 中间保留旧默认解析算法的预热版出现过 288.131ms 峰；最后缓存解析版为 73.490ms。稳态整体接近原基线，不能把 0.xms 差异写成全局卡顿根治。主机背景负载与 G1 Eden 大小未固定，前后 GC 次数不直接代表分配量，帧时表为本机描述性配对。局部 quad 的逐字节等价、528→192 字节分配与原同步邻域筛查路径消失的证据更直接。

最终两轮未命中 Embeddium awaitJobs 等待，Refining 邻域筛查进入 chunk future 的 JFR 样本均为 0（原无光影为 4）。API 预热后飞行窗口没有再采到新增 helper 的惰性类初始化。Solas 最慢帧的已采样栈转为 PlayerRenderer/ModelPart 的 Iris 阴影模型；另有一帧 53.40ms，其中真实 light drain 约 19.60ms，属于仍存在的加载工作峰。无光影 54.25ms 帧没有可归因的 Render JFR 样本，不将其强行归因于区块上传。巡航 clock100–579 最慢帧无光影约 16.60ms、Solas 26.14ms。

因此本轮解决了筋斗云已复现的闪断/材质抽动/人物漏绘，减少了化虹模型过渡和邻域探查开销；32 视距的新地形加载仍有偶发长帧，未标记为完全消除。
