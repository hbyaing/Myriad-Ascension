# 御剑与化虹逐帧连续性修复

> 验收更正：用户在运行 `d093878` 后确认人物和镜头稳定，但御剑拖尾、化虹特效仍抽动。下文保留该轮真实结构检查和安装记录；零历史重置、零漏画不能证明材质时间连续性通过。后续复现、修复及连续录像见 [FLIGHT_TEMPORAL_SAMPLING_20261101.md](FLIGHT_TEMPORAL_SAMPLING_20261101.md)。

用户 2026-11-01 的 7.283 秒录屏仍能看到御剑头部断接、红黑烟尾跳变及白蓝光带短时重现。2026-10-31 的速度、区块和历史长度检查没有覆盖这些全部呈现路径，不能继续据此宣称抽动已经解决。

## 修复范围

- **明确复现的历史清空错误**：八皮肤第一轮中，转弯/刹车出现 5 次化虹累计弧长骤降至零。化虹采样用较新元数据中的低速判断较旧缓冲姿态的高速位移，误判瞬移；改为同时考虑实际呈现速度，和普通御剑的校验规则一致。新增无瞬移路线不得重置历史的硬性验收。

- 飞行快照增加阶段、化虹阶段和强度，让它们与位置、滚转使用同一段已验证的缓冲时间。此前较新的实体元数据可以先于旧位置的播放到达。采样、头部、人物隐藏和普通拖尾交接都改用呈现状态。
- 共享姿态由 `RenderTickEvent.START` 的 partial 固定，模型动画或另一个消费者传入不同 partial 不再决定整帧姿态。历史末端和材质时间使用同一 partial。
- 普通拖尾和化虹平滑交接，不再用最新强度 `.5` 的硬开关。人物透明度也读取同帧强度。
- 距离及视锥裁剪改用实际绘制的插值姿态。骑乘人物原有的模型位移修正发生在裁剪之后，曾出现只画出拖尾、漏画人物和剑的真实帧；增加客户端裁剪适配和实机人物绘制检查。
- 本地御剑人物及载体的模型绘制不再等待其所在区块的地形网格编译；只绕过这两个位置的渲染编译门禁，不请求地形或改变物理就绪检查。八皮肤复验曾在后续周期发现 163 帧人物漏画，保留该失败作为新增检查的依据。
- 普通御剑亮芯按像素导数过滤并保持能量，去掉会让细亮芯在亚像素移动时明灭的宽度过滤上限。
- 世界烟团出生渐入、红光消散使用连续包络；保留当前局部烟头。烟图集明确使用线性过滤，此前 GPU 材质夹具使用线性过滤，而实际纹理没有同等设置。

没有恢复已删除的离散御剑粒子，没有改变飞行速度上限、碰撞权限或上一轮区块控制。网络格式版本从 109 升为 110，联机客户端和服务端需要配套更新。
