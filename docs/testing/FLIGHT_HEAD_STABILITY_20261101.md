## 共用头部的原因与修复

真实生产 `HuahongFlightPath` 和 `SwordFlightTrailHistory` 扫描没有发现 tick 边界 C0 跳变，但恒速、恒角速度圆弧在载体局部空间出现了重复 20Hz 形变。7m/t、10°/tick 时，距头 2m 横向峰峰约 8.44cm，其中 94.2% 方差位于 20Hz；15m/t 时该处约 4.3cm，5m 处约 22.94cm。纯固定曲率形状在载体局部本应保持不变，原实现却不断混入固定 tick 的历史折线。

- `HuahongHeadBridge` 只生成显示副本，前 2.5m 固定载体局部位置，2.5–8m C1 接回过去世界点；source 不变，时间/弧长不变，8m 外保留原 Node 实例。桥接权重跟随实际化虹强度渐入/退。
- 附着模式的 `HuahongFlightPath` 使头部位置和标架保持刚性，过渡区使用解析乘积导数接回原平滑曲线。Path 回接终点是 `max(8, oldHeadJoin)`，高速时可到 12m；helper 在 8m 外保留原 Node，不代表所有平滑截面也在 8m 外立即逐值相同。旧四/五参数构造仍使用原语义，普通御剑路径不被这项改动替换。
- 七种网格形态的 Path 仍读取 raw source；只在头部绘制位置使用显示副本。火焰与烟的离体出生仍从原世界节点计算，避免出生点随头绕转。虹核流星同样保留 raw 标架输入，蓝白虹流仅向体积队列提交显示路径，不二次桥接。

生产数学扫描 1,275,084 项通过；测试范围中原距头 2m 最大周期形变约 0.2989m 降到浮点误差量级。修改前真实 HEAD 影子类与默认 Path 的 25,728 组元组逐值一致。数学结果用于定位与回归，不单独充作美术验收。

## 普通拖尾与加载恢复

普通 0/2 材质虽已与飞行速度解耦，仍有约 5.4cells/s 噪声扫动和四倍 curl 明灭。候选把白蓝主芯从噪声门控中分离，边缘使用低频闭合域流动；保留空间颗粒、原物理芯宽、配色及 128s 周期。主芯微弯的两项横摆幅度由 .024/.015 收至 .016/.010，避免芯边局部反复变暗；蓝缘继续流动。螺旋出现、第二条螺旋、风环的三个非零 alpha 硬门槛分别改为 C1 渐入。柄后裁剪、band36 柔光及全部化虹材质分支保持。

加载控制另有独立缺陷：停止后即使只有一个 16m 新区块就绪，原最低 16m 储备加制动距离仍会让速度上限保持零，等待第二个区块。低速储备改为 `max(2, ceiling*4)`；高速原预算、四 tick 稳定条件、制动斜率与精确未知地形 sweep 保留。纯 7/15 档单区块恢复及再次安全停止等 115,292 项检查通过；前进意图为正时预取仍继续，不因实际速度零而停止发请求。

实际单 FULL 夹具采用独立未注册假玩家、真实 FULL 请求和每真实世界 tick 的控制器步骤，仅限制测试 UUID 的供给；先在测试已有可见区真实召唤挂载，再将仅测试载体移至远端 FULL；只移除测试 root 的自然 tick，防止人工/自然双步，不伪造 readiness，不改全局预算或其他实体。这是有限供给功能验证，不是自然加载性能基准。
