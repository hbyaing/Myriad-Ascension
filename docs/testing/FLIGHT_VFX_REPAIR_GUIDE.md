# 飞行拖尾与动态特效修复经验

用户于 2026-11-04 要求记录。适用当前 Forge 1.20.1 飞行消费者；每次续做须重读实际源码及加载包，不按旧截图、版本标签或曾通过的测试直接覆盖当前实现。本文区分稳定路径、材质运动和最终画面，不能把其中一项通过当作整项验收。

## 时钟、挂点与世界历史

- 大世界时间必须先转 double 再加 partial tick。`double now = longTick - 1 + floatPartial` 仍会先做 float 加法，赋给 double 已来不及；旧世界会丢失小数 tick，出现约 50ms 的伸缩与尾迹超越挂点。参照 `SwordTrailPhase.renderTick`、`FLIGHT_TICK_PRECISION_20261104.md`。
- 模拟固定 tick 采样，绘制只插值，不在每个 render pass 追加历史。同一画面里的模型、挂点、相机和历史边界使用同一插值区间；不把下一 tick 的位置接到本帧人物上。大坐标保留 double 到减相机位置之后。
- 客户端历史与材质采用关卡本地时钟，暂停不推进、换世界清理；服务器世界时间校正不能直接老化或清空本地尾迹。真实瞬移、跨维度要断带，合法高速移动不应误判成瞬移。
- 世界历史、原始出生时间和弧长留作事实数据，平滑只作用于绘制副本。不要为掩盖抽动改物理速度、相机或区块加载逻辑。

## 曲线、截面和生命周期

- 当前朝向与真实速度可不同。强制近端沿朝向接直，再短距离混回旧路径，会凭空制造回钩。前端、历史主带和材质截面应消费同一连续曲线，方向来自该曲线导数。参照 `FlightTrailCurve` 与 `FLIGHT_CURVE_CONTINUITY_20261104.md`。
- 原始折线、滤波曲线和硬直线的两套位置同时使用，会产生重叠、脱节与折角。验证同一弧长站点的真实提交位置，而不只比较挂点误差。
- 亮核和历史带分别收尾、淡入或使用不同平面时，会形成细腰。连续发光主带统一位置、宽度包络与截面朝向；宽度、年龄透明度、颜色与像素覆盖分别检查。
- 活动近端不要因旧历史点的年龄突然收细；远处残留仍须正常老化。静止、恢复加速、加减速与出入化虹都要验证，不能简单刷新所有出生时间。
- 细亮核须考虑亚像素覆盖和能量补偿。增亮、加粗或叠一层不能替代时间、位置和截面根因修复；几何半宽稳定也不自动等于最终像素亮度稳定。

## 稳定路径仍要保留动画

- 几何挂点稳定不等于把特效冻结。内部流动、烟体翻卷和红色裂光需要独立的有界时间相位；避免每 tick 随机重抽出生槽或高对比纹理。
- 高速移动不应直接驱动高频材质相位。筋斗云原先按距离累加流动量，又把高速位置带入世界噪声，导致跟随视角快速扫描噪声格。世界历史支撑保留，材质通过受控时间流动；不能用停止所有动画来换稳定。
- 红黑烟近端需有可见的连续烟瓣与轮廓运动。验证固定网格、固定相机时，仅推进材质时间仍有可见变化；再分别检查实际几何翻卷与飞行画面，避免把人物移动误当烟在动。

用户随后否决了 `0cf50e2` 的“已恢复流动”结论：固定网格有 RGB 差、半径在呼吸，仍可能只像整团烟平移。烟团需要可追踪的出生、后移、卷动、增长和主遮罩形变；固定侧视直飞下检查相对形变，不能只数变化像素。

筋斗云不能只让次级细节动、主体密度保持固定。降低帧间 RMS 需配合可见流动能量下限；目标是去掉高频跳变并保留低频翻卷，不是让 RMS 越小越好。当前消费者为 `HuahongFlowField.parcels()` 与筋斗云主体密度平流，旧固定槽函数不作为已验收动态基线。

## 渲染通道

- 多张透明烟片交换顺序可导致片状闪烁。稳定排序本身不保证没有交换，需用同一网格反序提交作对照。当前红黑烟的光学混合在该夹具中顺序差为 0；它是近似体积混合，不是真实流体或精确排序体积。
- 透明输出、混合函数、深度与 Bloom 是不同环节。烟应能吸收，仍受场景深度遮挡；白色亮核和光晕不应把黑烟变成加法黑色。
- 原生与光影后绘制通道都要显式绑定 sampler、纹理过滤与本次 uniform。绕过 RenderType 的晚绘制不能继承猜测中的纹理状态；筋斗云 Worley 图集两路都核对实际 LINEAR 过滤。
- 暂停、停止与转向后，不要让当前载体继续旋转已停止发射的整段旧密度场。资源重载和退出世界清理缓存，绘制后恢复 GPU 状态。

## 验收方法与曾经漏检的情况

至少覆盖：刚入化虹、退出、直行、加速、减速、停住再走、低速启动、快速左右转、180° 反向、大俯仰、不同观察方向、旧世界时间、大坐标、原生及实际所用光影。保留连续录像及真实采样时间，截图用于看局部，不能单独证明没有时间抖动。

根部轴线误差很小，曾经仍漏掉过渡段回钩；主带综合支撑稳定，曾经仍漏掉两套位置和不同截面的细腰。因此需同时核对轨迹、曲率、实际提交截面、材质时序、裁剪后的像素及用户现场观感。原始几何回转可能被裁剪隐去，记录时不能把隐去几何的指标冒充可见折角，也不能删去不利样本。

构建、CPU 数学、GPU 材质夹具、独立客户端录像、用户实例当前实际加载版本是不同证据。记录源码/资源哈希与测试条件，正式包排除 QA 和鼠标保护；独立客户端不得捕获用户真实鼠标。区块生成卡顿、服务器移动校正、GPU 材质闪烁分别定位，不能用降低用户 32/32 距离或暗中限速代替特效修复。
