## 直接复现的渲染缺口

`SwordTrailStateQa` 调用真实 `SwordFlightTrailRenderer.drawPost` 和正式材质，在主目标上绘制单个诊断面。分别预置正常状态、反向混合公式、原生混合因子与缓存不一致、残留发光通道标记。

旧代码正常状态像素 RGB 为 `[43,105,127]`，后三种状态均变为 `[0,0,0]`。修正后四种状态均为 `[43,105,127]`，最大 RGB 差为 0。这证明提交入口依赖外部残留状态的缺口得到修正；诊断面不是连续飞行验收，也不能单独证明原录像中是哪一个调用者留下了状态。
