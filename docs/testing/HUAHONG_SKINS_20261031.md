# 化虹皮肤与御剑尾迹续作（2026-10-31）

后续高度边界、近端衔接及耗灵降低的修复见 [御剑与化虹修复](FLIGHT_REPAIR_20261031.md)。本文保留该轮历史验证。

新增八种化虹外观及背包设置切换，继续处理“御剑化虹”聊天中的剑尾挂点、抽动、过细过暗与飞行地形加载问题。此记录是专项验收，不是整个模组完成验收。

## 行为与来源

- 路径：背包 → 设置 → 御剑飞行 → 化虹皮肤。按钮使用现有 `CultivationUi.Action`，选择立即持久化，登录和重生重新同步。协议 108 / C2S ID 96；其他客户端从飞剑同步元数据渲染所选皮肤。
- 八种皮肤：虹核流星、燃尾流星、贯空长虹、开放流羽、红黑离烟、赤焰撕裂、扇形流霞、蓝白虹流。默认虹核流星；采用当前 minecraft-huahong 中仍有效的形态，不恢复已经删除的研究入口。
- 虹核流星适配独立 V9 几何。其他形态在项目内以历史路径、光膜、火舌、烟团和三维截面实现。未复制许可未确认的蓝白虹流 V13 参考代码；不能称为其体积算法的精确移植。
- 原化虹条件、速度和消耗保留。服务器拒绝非法皮肤 ID，切换不授予化虹、穿墙等能力。

## 自动化与实机

- `gradlew verifyFull --offline`：484/484 必需 GameTests 通过。覆盖真实服务器移动、化虹费用及速度、皮肤元数据与偏好、非法 ID、分帧矿脉扫描一致性、旧区块保护、边界碰撞与非阻塞地形就绪检查。日志中损坏炼丹日志错误为既有故障注入，其用例通过。
- 碰撞微基准：20 次样本，原细扫 24.3104 ms，优化后 2.5955 ms。仅描述这个空段/障碍扫描测试，不作为整体 FPS 或新区块生成耗时的测量。
- 皮肤截图要求真实客户端实体处于 stage 2、strength ≥ 0.995；每种皮肤均记录直飞与缓转。测试角色在每组开始补充灵力，避免旧测试因灵力耗尽将退虹截图误判为外观通过。
- 设置页验证 1920×1080、2560×1440，分别采用 GUI 选项 3、4；逐个点击八个按钮、核对配置、页面切换后的缩放及外框边界；记录普通、悬停、焦点/禁用状态。悬停通过 QA 客户端内部鼠标坐标模拟，未移动真实指针。
- 正式代码中近乎重合的尾迹末端也精确采用模型挂点。剑尾专项涵盖四把剑、直飞、转向、滚转、后绘制和制动；不以单次截图代替连续挂点记录。
- 修正新皮肤噪声与细筋的周期，使 256 格弧长重置、128 秒着色器时钟循环连续。QA 提取正式 GLSL 的实际材质函数，在游戏 OpenGL 上渲染 RGBA32F 对照图，检查 16 组周期对照及原生/后绘制函数一致性；不以另写的近似公式代替真实 GLSL。

最终结果：正式 `build --offline` 通过；无光影与 Solas 每组均获得 16 张稳定皮肤截图、12 张设置截图，报告 `failures=[]`，周期对照最大通道误差均为 `0.0001697540283203125`。剑尾无光影 698 帧、Solas 672 帧，末端挂点最大误差均为 0。独立客户端全部正常保存退出，指针捕获违规均为 0。正式 JAR 已检查无 QA、GameTests 和鼠标保护代码。

## 边界
