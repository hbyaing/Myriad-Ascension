# 御剑根部接直、化虹动态衔接及八种形态加宽

本轮本地交付，不上传 GitHub。保留其他成员的提交，远程 `origin/main` 是本地开发分支的祖先。化虹 Skill 源工程、安装副本与清单的 39 个文件核对一致；修改的是游戏消费者。

## 实现

- 御剑拖尾根部原来直接连向旧位置，急转时旧路径会把剑柄附近拉弯。现在挂点后 0–0.5 米沿当前剑轴接直，0.5–1.5 米平滑过渡到世界历史；更远的节点保留原实例、时间和弧长。变为化虹时先保留这段根部，再叠加原有化虹附着权重，避免切换时撤掉接直约束。
- 虹核流星、贯空长虹：转弯或短暂停顿时，近端主光带原先继承老历史点的年龄，局部亮核却保持完整。恢复运动后新历史点又变亮变宽，形成突变。现在 0–6 米附着段使用活动载体的支撑年龄，6–12 米平滑交回真实历史年龄；外部历史与退出淡化仍按原生命周期处理。
- 用户随后要求所有化虹加粗：八种形态共用横向比例由 1.8 改为 3.6，约为此前两倍。亮核、尾带、羽膜、火舌、烟团一同加宽；虹核伴流的横向展开及红黑烟的厚度同步扩大。蓝白虹流的体积半径、积分包围盒、核心半径也与该比例一致，避免只放大表面或被旧边界裁断。
- 没有用提高材质亮度替代尺寸调整。保留前轮 double 精度渲染时间修复。
