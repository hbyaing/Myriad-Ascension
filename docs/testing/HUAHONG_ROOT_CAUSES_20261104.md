## 透明烟层的排序交换

真实飞行旧候选记录 `reports/flight-bright-20261104/all-native/capture.json` 中，红黑离烟前端切片有 106 对相邻帧发生顺序交换。部分帧有几十对红光与黑烟交换相对顺序。原实现按切片中心到相机距离排序；相交透明卡片的中心排序无法保证每个像素的正确遮挡，红光的加法与黑烟的吸收也不能交换。

GPU 隔离试验使用实际 `HuahongSkinGeometry` 产生的 2304 个顶点、实际生产着色器及 `drawPost`，固定几何、时间、相机、背景和深度，仅倒转四边形顺序：旧合成的最大 RGB 差为 48/255，有 4625 个通道差超过 3。该试验直接证明排序本身足以导致跳变；不是根据几张不同时间的截图推断。

红黑离烟现在先在 RGBA32F 目标累计光学厚度及光，再统一合成。吸收量使用 `-log(1-alpha)`；光学混合不依赖切片提交顺序。同一试验修正后的最大差为 0。这是均匀介质混合近似，不宣称精确的分层体积输运；烟色、形状、原纹理与六层切片保留，红光与黑烟的混合观感仍需要用户验收。

新增一个仅在烟形态使用的全分辨率浮点缓冲：1280×720 约 14.1 MiB、1920×1080 约 31.6 MiB，随尺寸变化重建，离开世界释放。没有以截图回读测试冒充 GPU 性能测量。

## 亮芯的亚像素漏采样

旧 `coreHalfWidth` 的覆盖下限相当于约 0.85 个屏幕像素，另有物理宽度最多扩张 8 倍的上限。亮芯材质又在边缘衰减，即使中心与形状完全稳定，穿过光栅采样点之间的间隙也会整段消失。多个重叠亮芯层交替漏采样，会看起来像其中一段突然抽动，不能据此判断实体或曲线中心真的跳动。

GPU 隔离试验冻结旧生产 GLSL、直线形状、时间与相机，仅通过 32 个小于一像素的平移位置。模式 8 的旧亮芯有 9 个位置完全无输出，模式 22 有 7 个；累计红通道能量分别在 0–78、0–51 间变化。

现在以捕获的世界投影计算约 3 像素的光栅覆盖，移除破坏覆盖下限的倍数上限，保留 `physical/covered` 的透明度补偿，并对两种亮芯边缘按像素足迹进行解析积分。它扩大的是采样支持，不是提高物理亮芯亮度。相同试验两种模式均为 0 次消失，能量范围分别为 19–22、14–16。仍有 8 位目标量化与边缘截断误差，不把它写成完全无波动。
