# 恢复红黑离烟与筋斗云的实际流动

用户否决了上一候选：烟团仍像静态图整体平移，筋斗云流动也被压没。此前固定网格 RGB 差、半径呼吸与低 RMS 的检查不够，不能据它们声称已经恢复原动态。本轮保留稳定时钟、公共曲线、透明混合，修正真正的运动与密度场。

开始时普通合并了远端成员提交 `ce3c4c5`（构建验证约定拆分），保留双方历史，没有重写或上传主线。

## 实际改变

- 红黑烟：移除跟随人物的固定 33 槽主体和八卡头壳，改为连续时间出生的烟团。身份按出生时间固定，烟团沿真实曲线向后平流，绕轴卷动并增长，出生/消散平滑淡化。世界空间远尾残留继续老化；飞行速度不直接重抽烟团图样。
- 烟的主要遮罩也参与连续旋转与形变，避免仅让亮度/内部噪声变化、外轮廓始终是同一张照片。保留黑烟吸收、赤红局部密度、场景深度和光学混合。
- 筋斗云：恢复主体密度纹理的平流，次级卷曲与主体相互作用；运动量仍以时间有界推进，避免重新绑定高速世界距离。云形相位由 11/17/23 秒改为 5/7/11 秒，流动上限从 0.05 恢复到 0.20 纹理周期/秒。未修改飞行速度、大小、相机、用户距离设置或筋斗云人物姿态。

固定侧视用正式相机，只把玩家观察朝向固定在运动侧面。实测挂点屏幕位置全程变化约 0.002×0.003 像素，速度约 14.975 格/tick。烟色结构光流扣除整体二维相似变换后，44 对图像的中位残差约 3.95 像素，原始数据在 `nonrigid-video-analysis.json`。该光流仅作“不只是整体平移”的诊断，不能证明是真实流体，也不是用户美术验收。

筋斗云同一 GPU 密度夹具中，主体时间变化能量由上一弱流动候选约 0.000197 恢复到约 0.001034；历史尾约 0.000048 恢复到约 0.000167。同时 8Hz 以上能量比例仍约为 0.25% / 0.35%，低于旧高速扫描的约 40% / 91%。新增可见流动能量下限，不能再把 RMS 越低当作越好。实际两组高速场景没有误断带或时钟回退，峰值约 10.79 格/tick；62 项实际 Track/Clock 检查保留。
