# 普通御剑尾迹的剑柄边界

用户截图要求优先修复普通拖尾越过剑柄，必要时允许相近替代。基线为 `c9b9c823dd18e905fad0c11d10d12c1610a67f57`；参考 PNG SHA-256 为 `58989f9644d1a1907d8d41b1aa6917c29da43e3c3662d7980cc357137c2c5851`。

## 原因与实现

实际模型后端测量与现有附件点误差最大约 `7.86e-8m`，不是固定挂点前移。旧版近端截面、螺旋与风环没有剑柄平面约束；转向时历史位置也可能进入当前柄前半空间。修正后的旧版实机探针在柄附近 2.5m 范围内记录到约 2.166m 的前越。此外，普通尾迹也进入半分辨率屏幕 Bloom，模糊可将光扩散至柄前，场景深度约束无法阻止这类扩散。

- 保留真实模型测量、飞行姿态及历史点。新增 `SwordTailClipper`，按实际柄后端和当前剑轴，将所有普通主束、螺旋、风环的真实三角形裁到柄后 `.01m`；交点位置、UV 和透明度插值，不把越界顶点钳成亮线。
- 柄端宽度在 `.35m` 内 C1 展开，透明度在 `.22m` 内渐入；螺旋根部收零，风环移至柄后。远端旧尾在越过平面前最后约 30° 逐渐淡出，避免急回头时整段突然被裁掉。
- 普通尾迹使用独立的有限蓝白柔光 band36，不再进入全屏 Bloom；原 band0/2 的亮芯、配色和材质流动保持。化虹仍进入原有发光缓冲。

急回头时，位于当前柄前的旧尾会淡出，再从柄后生成新尾；不承诺这种情况下保留一条等长的前方旧轨迹。此行为满足剑柄边界，并保留近似蓝白剑气外观。
