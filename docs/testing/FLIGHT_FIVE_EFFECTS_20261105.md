# 五项飞行特效本地候选（2026-11-05）

本轮处理扇形流霞立体感、蓝白虹流耗时、赤焰撕裂尖刺、红黑离烟转弯和筋斗云动态。已完成本地构建、独立客户端检查及测试实例安装，等待用户观感验收。没有向 GitHub 写入。

## 实装与证据

- **扇形流霞**：原先六条纱流的中心都沿同一个横向斜面展开，卷边不足以形成空间层次。现在出生方向对应不同空间方位，六条纱流有各自的展开、卷曲截面和法向亮边。仍是开放的薄纱曲面，不是刚性翼板或体积积分。实际提交的透明网格横截面加权协方差小/大特征值比最低 0.4328；改变当前载体朝向，旧纱流坐标不变。`fan-orbit.mp4` 使用 QA 环绕相机，`FAN-gameplay.png` 为正式相机的 Solas 实机。
- **赤焰撕裂**：单纯柔化各条尖根后，近景仍出现宽曲面在急弯处外翻的针刺。最终合并前端根部，增加根部采样，柔化不透明度，并为火舌使用弯曲的六列截面、沿轨输运的横向框架及曲率限宽。减弱几何中的高频横摆，保持材质侵蚀、后方分叉和碎芒。采用 `flame-final-native`、`flame-final-solas` 专测作为当前视觉证据；早期尖刺图已归档。
- **红黑离烟**：用户确认问题是“整条烟尾像硬杆跟着前端转”。旧主烟团在头部后固定弧距不断重排，转弯时缺少真正留在旧路径上的主体尾迹。现保留短前段连贯翻卷，在 7–16m 逐渐接入从真实世界历史发射的烟团，远端在 55–84m 与真实寿命结束前渐散。旧烟中心只由出生坐标及自身年龄决定，保留扩散、漂移和红色烟光。实际消费者对照 121 个同一出生编号，直行与转向 90° 的旧烟位置误差为 0；120fps 子步漂移不为零，最大约 0.01288m。见 `smoke-turn.mp4` 固定世界方向镜头及 `smoke-turn-solas.mp4` 正式相机。
- **筋斗云**：在主体密度上恢复闭合的局部卷动，增强低频轮廓翻卷与细节；移动时的后向平流仍由真实移动启用，上限 0.32 个图集周期/秒，避免重回随世界速度扫描的噪声。静止时只原地翻卷。实际无光影侧视的 122 个静止帧、Solas 的 51 个静止帧均速度 0、尾段数 0、后向相位变化 0；固定侧视中云轮廓仍有约 14.5% 的最大掩码差，配合实际密度探针确认并未冻结。GPU 的静止主体时间变化能量约 0.001266，8Hz 以上能量占比约 0.66%；动体约 0.77%（旧世界扫描探针对照约 40.21%）。见 `cloud-native/review.mp4` 固定侧视、`cloud-solas/review.mp4` 正式相机。

已核对当前 `minecraft-huahong` 源、安装副本 39 文件；扇形流霞以实际 `fan-lookdev.js` 为参考，按用户要求增加空间分层，不宣称工作台与 Forge 像素完全一致。用户附件保留在 `references/`，未修改 Skill 或其他形态。

## 蓝白虹流性能

按 `minecraft-vfx-performance` 区分 GPU pass 和整游戏帧率。保留全分辨率渲染、128 次积分、深度遮挡、世界曲线和原有颜色/运动。缓存同一 GPU 哈希产生的周期梯度（512×512 RGBA32F，4 MiB），并用保守分段包围球跳过权重低于约 2e-22 的段。缓存的是梯度，密度、采样和运动每帧仍实时计算。资源重载、退出世界释放缓存；生成失败可走直接哈希。

单做缓存的首轮仅约 3% 加速，且直接把两项优化应用于所有角度会使正对飞行轴线的视角变慢。最终按相机位于前端的方向选择保留的原始着色器程序，避免仅关开关后仍有复杂程序的额外成本。两个程序和 QA 冻结基准逐字节关系有记录；旧本地 V13 参考适配的来源与公开边界保持不变。

RTX 4060 Ti，实际完整 shader、相同路径/时刻/深度/RGBA32F 目标。每组两对预热、七对交替 GPU elapsed query，以下为中位数：

| 视角、积分目标 | 原耗时 | 最终耗时 | 路径 |
| --- | ---: | ---: | --- |
| 侧面 320×180 | 2.937ms | 2.346ms | 缓存与分段排除 |
| 斜前 320×180 | 2.123ms | 2.122ms | 原程序 |
| 正前 320×180 | 1.418ms | 1.418ms | 原程序 |
| 近景 320×180 | 3.966ms | 3.285ms | 缓存与分段排除 |
| 近景 640×360 | 9.149ms | 6.862ms | 缓存与分段排除 |

五组浮点像素对照最大及平均误差均为 0。受测加速视角 GPU pass 耗时约减少 17%–25%；这不是整游戏 FPS，也不是所有设备、分辨率的保证。首次缓存生成未计入热态耗时。实际 1280×720 客户端另行观察外观与光影兼容。详细数据 `dense-perf.json`。
