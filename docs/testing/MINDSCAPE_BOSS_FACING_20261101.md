# 心境Boss出场朝向修复 · 2026-11-01

原心境生成入口只通过`moveTo(...,180,0)`设置实体yaw，未初始化独立的身体、头部朝向和首帧插值值。心境Boss使用NoAI等待玩家凝出心剑，战斗控制器在等待分支直接返回，导致身体/头部继续保持默认朝向，玩家看到背面。

## 修正

生成时按Boss出生点到玩家入场点的实际水平向量计算yaw，在实体加入世界、开始客户端跟踪前同步实体、身体、头部及三套前帧yaw。统一入口覆盖六贼、三尸和最终心魔十个正式挑战；不改全局模型朝向或玩家镜像。

等待心剑期间使用当前玩家位置更新朝向；出招与预警仍沿用原战斗控制器的目标和转向逻辑，不将战斗全程强锁到玩家。心魔切换第二阶段沿用实体的正确朝向。
