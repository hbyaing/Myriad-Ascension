# 高速御剑与化虹的材质抽动复现

用户实际运行 `d0938784b13e938467cb5159b9df265ed818513d` 后反馈特效仍抽动，并明确人物、镜头较稳。已核查实例磁盘包哈希及用户 JVM 启动时间，该轮失败不能归因于未加载新版。此前历史重置和人物漏画计数没有覆盖此次材质闪变。

## 已复现原因与改动

- 材质原来读取世界累计弧长。约 300 格/秒时，跟随头部的窄纹理会以远高于显示帧率的频率换样。现在历史顶点仍保留世界位置，材质改为距呈现头部的连续弧长，仅由显式材质时间控制流动；PRISM、FAN 的横向小波形也采用相同局部相位。
- 红黑离烟原来每 .55 格生成新的随机烟团。实测 14.875652 格/tick 时每秒约 541 个新单元，24 格主体约 80ms 就换一遍。改为真实曲线路径上的稳定采样槽及连续低频流场；保留红黑密度、24 格包络和渐隐，后段弱残烟仍停留在真实历史位置。新烟体只有在历史路径已达到相应长度后才渐入。
- 头部固定 .25 格的平滑区在高速下会在数毫秒内吞掉一个 tick 的转角。平滑范围改为按最近两 tick 的实际弧长速度计算，并有上限；近端御剑光带使用沿载体平滑运输的两张交叉光片，渐变接回远端朝向相机光片，避免近轴视角下宽度方向突变。
- 最终复核发现 DENSE 体积化虹使用独立世界坐标噪声，未被光带相位修复覆盖。其云体及等值线细丝改用同一呈现头部的正交材质标架，梯度同时转回世界空间以正确过滤射线及像素足迹。真实历史包络、场景深度、128 步积分、密度及细丝亮度保持原值；不用最近路径段的离散归属作为材质坐标。
- DENSE 停止生成后，残留历史使用最后一次生成时的材质朝向，继续按真实历史年龄消散及显式时间流动。若继续读取退出后转动的剑姿态，静止尾迹会重新扫过材质噪声；首轮体积候选真实退出录像暴露了此边界，因此其退出结果保留为失败，不能用飞行段改善替代。
- FLAME 的后段残影原来在出生 .04 秒时直接以约 .30 透明度出现，改为 0–.04 秒的 C1 渐入；世界出生位置、固定 cell 身份及 .04 秒后的原有形态和透明度保留。

本轮修改客户端呈现，未改变飞行速度、穿墙权限或区块流送逻辑，也未恢复已删除的离散御剑粒子。

## 针对性检查

- 同一正式 GLSL 的 GPU 材质夹具，以 300 格/秒世界弧长扫过和头部局部相位作对照，二者显式时间均推进。帧差 RMS 从 .122118 降到 .006884，约降低 17.74 倍；平均信号 .224256 → .225337，保留动画和亮度。这是材质场检查，与实机连续画面互相补充。
- 实际体积 GLSL 的独立 GPU 探针同时包含 300 格/秒平移及 yaw/pitch/roll 转向。帧差 RMS .044141 → .000484，约降低 91.22 倍，平均信号 .014687 → .014349；刚体平移旋转的局部场最大误差约 .00000489。显式动画保持非冻结，密度/细丝参数未下调。旧域源码快照仅位于测试资源中，正式 JAR 不包含它。
- 实际生产 `HuahongFlowField` 的 46,560 项检查覆盖 128 秒周期及边界，避免新增长时接缝。
- 实际生产路径/近端截面在 5、15、30 格/tick 和每 tick 3°、10° 转弯的 30,240 项检查通过；同一检查明确拒绝旧 `d093878`。旧版 15 格/tick、3° 转弯时头部切线峰值约为模型转速 83 倍；新版最终近端宽度向量测试最大约 2.73 倍。
- 生产历史弧长和相位回归共 1,220,041 项通过；原有路径转向、近轴视角、亚像素亮芯检查保留。

本轮不作为所有皮肤的完整美术还原验收。区块卡顿、穿墙仍需各自的实机场景，不能由材质连续性结果替代。
