# 御剑回钩、化虹折角与细腰：连续路径修复

本轮根据用户新增三张截图继续修复，仅本地交付，不上传 GitHub。此前“根部接直”的实现已被本轮替代，不能继续用此前轴线误差很小作为曲线自然的验收依据。

## 根因与实现

1. 御剑按当前剑轴强制接直半米，再在一米内混回真实历史。转向与实际移动方向不一致时，这个位置混合会把原本平直的轨迹拉出回钩。化虹也有固定直段接回历史的问题。
2. 化虹局部头部使用滤波路径，部分历史尾带却使用另一套原始位置混合；两者在转弯处并不重合。此前近端主带检查只看轴线与综合支撑，漏掉了这处位置分歧。
3. 贯空长虹与虹核流星的发光头、历史带分别提交，宽度包络与平面朝向不同。亮核收尾、历史带淡入和视角变化会共同形成细腰。

新增 `FlightTrailCurve`：沿真实历史弧长对位置作正权积分滤波，靠近挂点时核宽连续收束到零；挂点位置保留。没有把当前转向轴硬塞入旧轨迹，曲线方向取实际曲线导数。世界历史原始节点与记录时间、弧长均不改写，滤波仅用于绘制副本。

御剑绘制副本与化虹路径采用同一个位置算法。化虹历史行与局部层都使用公共路径位置，蓝白虹流也消费相同滤波副本。原有 double 渲染时间精度修复与上轮约两倍横向尺寸保留。

贯空长虹、虹核流星的主要发光体改为连续主带：鼻尖仅在前端收束，挂点后 0.75 米达到完整截面；不再把单独局部亮核叠在历史主带上。主带宽度不再因某段历史较老而局部缩小；尾部生命周期仍通过透明度处理。保留各自的金白、虹色材质与虹核附属伴流。
