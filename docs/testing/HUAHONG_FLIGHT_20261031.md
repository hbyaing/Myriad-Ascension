# 御剑化虹专项验证（2026-10-31）

以下保留首版及去光球迭代的历史证据。八种皮肤、最新剑尾和地形加载修复见 [化虹皮肤续作验收](HUAHONG_SKINS_20261031.md)；当前默认外观与协议以该续作和设计说明为准。

范围：归元、天阙的化虹能力，以及现有御剑/遁虚、灵力扣费和客户端着色器接入。此记录不是项目整体完成验收。

## 已验证

- `gradlew verifyFull --offline`：483 项必需 GameTests 全部通过，含新增真实服务端御剑移动、两倍速度、独立碰撞权限、替代普通维持费及制动恢复检查。日志中的损坏炼丹日志隔离错误属于既有故障注入测试，其用例最终通过。
- `gradlew build --offline`：正式包构建、资源检查、全部已配置专项检查、回归和 GameTest 源编译通过。新增纯 Java 回归覆盖品阶边界、实际速度门槛、连续稳定时间、只扣一次入虹费用、倍率上界、立即撤销速度加成、显形、冷却和灵力不足。
- 独立隐藏客户端，无光影与 Oculus 1.8.0 / Embeddium 0.3.31 / Solas Shader V3.7b 均完成验收。实际服务端遥测的稳定速度比值为 `1.999999935733915`，不是客户端指定速度。
- 两组客户端各保留 10 张原始截图：聚虹、原生绘制、缓转、后绘制、实体遮挡、第一人称、退虹、恢复、天阙金色及关闭特效。已查看关键画面，确认人剑隐藏、细芯与柔晕、尾迹受世界遮挡、显形和关闭特效后的模型恢复。
- 客户端报告均无失败、截图采样 GL 错误为 0。测试专用指针保护记录零捕获违规；没有操作用户客户端或真实鼠标。测试结束通过正常客户端退出保存世界。
- 元数据新增化虹阶段和强度，协议提升至 107，使旧客户端在握手时拒绝不兼容连接。

## 尖头高光修正

用户指出虹线中部偏亮、尖头反而偏暗。旧头部材质使用 `sin(pi * U)`，亮度峰值位于头部中心；第一次修正改为沿飞行方向递增的亮度，并在实际前端挂接独立光核。用户进一步指出前端圆形光球违和，当前版本已删除独立光核几何及圆形材质，改由虹线自身收窄成锐利尖端，亮度沿线向前增强，薄晕贴合线条。原生、后绘制和选择性 Bloom 共用该材质。

当前无光球版本的复验记录位于 `reports/huahong-no-orb-native/`、`reports/huahong-no-orb-solas/`；尖头局部裁图由原始实机截图直接裁切，保留原图作对照。上一轮记录保留在 `reports/huahong-tip-native-final/`、`reports/huahong-tip-solas-final/`。
