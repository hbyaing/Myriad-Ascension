# 五术 · 功法特效工作台

从统一工作台打开功法特效对照。上排是主动施术，下排是被动触发。十个画面共用播放、进度、速度、视角和环境亮度。“画面”菜单可放大指定术法，左右对照主动与被动。拖动任一画面同步转动，滚轮缩放。参数 `?art=1` 打开回春术，`?art=4` 打开净化术，`?art=3&t=2.31` 暂停在嗜血术命中的一刻。

8 秒循环用于审阅。主动轻身、聚灵和嗜血的游戏持续时间由功法熟练度决定。工作台模拟缓降、生命恢复、灵力补充、近战命中及负面状态移除等触发。

页面使用 WebGL 2 和程序化方块人物。轻身按历史位置生成跑动风纱，被动缓降时在足底出现托举气流。回春的半透明绿叶绕身飞舞，青光贴着玩家表面自下而上闪过。聚灵以冰蓝流光沿曲线收向灵核。嗜血的墨团贴随武器，命中时从剑尖迸开。净化主动的银冠从头顶落下，清除负面状态时灰墨剥落成银屑，落地后银环向外散开。被动回血时两道银弧从胸口掠开。工作台和游戏分别验证，画面中的人物模型和光照会有所不同。

`?art=design` 并排打开两套主动攻击草案。冰锥术在 8 格长、1.8 格宽的直线上掠过，命中木桩时出现碎冰和霜纹。烈焰波以近地火锋扫过 6.5 格、108° 的扇面，命中木桩会短暂引燃。工作台模拟飞行、扫掠和目标反馈，供验收设计。
