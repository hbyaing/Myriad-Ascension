# 五术 · 功法特效工作台

从统一工作台打开功法特效对照。上排是主动施术，下排是被动触发。十个画面共用播放、进度、速度、视角和环境亮度。“画面”菜单可放大指定术法，左右对照主动与被动。拖动任一画面同步转动，滚轮缩放。参数 `?art=1` 打开回春术，`?art=4` 打开净化术，`?art=3&t=2.31` 暂停在嗜血术命中的一刻。

8 秒循环用于审阅。主动轻身、聚灵和嗜血的游戏持续时间由功法熟练度决定。工作台模拟缓降、生命恢复、灵力补充、近战命中及负面状态移除等触发。

页面使用 WebGL 2 和程序化方块人物。轻身按历史位置生成跑动风纱，被动缓降时在足底出现托举气流。回春的半透明绿叶绕身飞舞，青光贴着玩家表面自下而上闪过。聚灵以冰蓝流光沿曲线收向灵核。嗜血的墨团贴随武器，命中时从剑尖迸开。

`?art=design` 并排查看重制版冰锥术和主动净化术。`?art=4` 并排查看净化主动和被动。`?art=flame` 打开此前的烈焰波草案。

冰锥术演出以一主六辅的冰锥齐射为主体。阶梯冰棱由立体网格构成，裂纹和霜面在着色器内生成，折射采样取自绘制冰锥前的场景副本。工作台演示同一条 8 格攻击方向上的冰锥、长霜尾和命中反馈。净化主动由四道玉印接走剥离的污痕，最后地印散去。被动在双肩亮起短促的玉印。两套重制演出供本地工作台验收。
