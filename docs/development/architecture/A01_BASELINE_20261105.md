## A02 调查结论

生产代码中 startV5Batch 的调用集中于 AlchemyService 的自由/配方两个分支；另有多个 V5 GameTest 调用 boolean 兼容入口。

改造应先保留这些调用者的正常与拒绝行为，考虑新增领域内结果及旧入口委托；不应同时重写批次日志和领取回执。尤其 journal.write 可能在批次文件写入后、认证或研究记录时抛异常，不能把所有异常都标为无提交拒绝。尚未实施该 Java 改造。
