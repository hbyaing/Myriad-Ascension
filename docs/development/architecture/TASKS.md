## A01 执行提示

架构工作区曾使用稀疏检出。先检查实际文件和构建输入，不把 git show 可读误当成完整工作树。`-PentryUiOnly` 选择整个 wuxingxiantu_entry 命名空间，不能报告成“只跑 V5BatchGameTests”。测试命令与选择范围以执行时 build.gradle、gradle/verification.gradle 为准。

如基线测试已有失败，记录失败阶段、复现方式和对当前任务的影响；不通过删除测试、放宽警告预算或隐藏失败来建立绿色基线。

## A02 不变项与待调查点

- 保留现有规则快照、批次身份、日志、领取回执、旧任务兼容与玩法含义。
- 调查 boolean 消费者、菜单提示、网络准入和异常边界；不能只看单个方法。
- 现有写日志后的异常不一定代表“没有提交”；应能指引查询/恢复，避免重复扣料和奖励。
- 不预设必须新建服务类或通用结果枚举。若局部封装足以兑现行为，优先比较它。
- 本地 Java 变更与服务端验证已完成；记录不代替客户端实显验收或发布授权。
