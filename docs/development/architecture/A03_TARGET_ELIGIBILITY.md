# A03：法宝与御剑目标资格

基线 `7d3df2f`。保留当前玩法，无存档、同步或目标计算改动。本地交付。

## 实际规则与责任

`yujian/YujianController.canTarget` 同时用于初始锁定、追踪、阵法范围伤害、路径碰撞和飞行冲撞。它要求：不是施法者、存活、非盟友、非自己的驯养动物、玩家目标通过 `canHarmPlayer`、施法者对目标有视线。

`artifacts/ArtifactEffects.target` 已直接复用上面的资格，再排除旁观者、幡魂、任何有主的 OwnableEntity 和盔甲架。它用于 LivingHurtEvent 上的法宝吸血、减速和雷击增伤。这个附加排除不应反向改变御剑伤害。

| 场景（其余条件满足） | 御剑 canTarget | 法宝 target |
|---|---|---|
| 普通活体、野生狼 | 允许 | 允许 |
| 自己、死亡目标 | 拒绝 | 拒绝 |
| 同队盟友，包括开启友伤 | 拒绝 | 拒绝 |
| 自己的驯服狼 | 拒绝 | 拒绝 |
| 别人的驯服狼 | 允许 | 拒绝 |
| 幡魂，未另行认定为盟友 | 允许 | 拒绝 |
| 盔甲架 | 允许 | 拒绝 |
| 旁观玩家，canHarmPlayer 允许 | 允许 | 拒绝 |
| 实体墙遮挡视线 | 拒绝 | 拒绝 |

这是**资格**矩阵，不是伤害保证。例如旁观玩家可能通过御剑资格，但底层伤害有自己的拒绝条件；不得据此声称实际能攻击旁观者。服务端 PvP、队伍与最终伤害裁决也不能互相替代。

## 结构取舍

比较三种方案：

- 原样复用并标明消费者差异：已有一份共同基础，无额外状态与迁移；本批采用。
- 将整个 target 统一：改变御剑对他人宠物、幡魂、盔甲架等的现行选择，违反本轮保持玩法边界。
- 新建通用事实快照或可注册策略框架：目前没有需要独立替换这一层的第二个实际需求；会新增类型、装配与维护路径，当前证据不支持。

生产改动只添加两处边界注释。没有为了目录或共享代码数量引入抽象。将来若某种法宝需要穿墙，就应重新审查该法宝的资格，而不是继续无条件继承御剑视线规则。

## 验证

`TargetEligibilityGameTests` 新增五项测试：基础/宠物/幡魂/盔甲架矩阵，队伍/友伤/旁观者矩阵，实际方块遮挡与恢复，法宝真实 hurt 事件消费者，御剑真实阵法末段范围伤害消费者。
