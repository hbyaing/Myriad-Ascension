# 第11项：储物袋与内容物品核对

2026-10-21。五行为主数据/战斗/修炼框架，来源提供存储与内容物品，不另建玩家修为或掉落账户。

| 项目 | 入口与规则 | 已有证据 |
|---|---|---|
| 储物袋 | BagData使用主世界同一SavedData，物理袋UUID索引；BagInventory以long数量保存精确NBT/药龄分桶，优先提取低药龄，不在袋内自动增龄 | StorageBagGameTests：超int数量、溢出拒绝、原始NBT/药龄守恒 |
| 实际背包/便携合成 | BagMenu锁物理袋、原生存取/筛选；认主输入先校验，产物继承主人后才消耗；不把储物袋当作灵石主钱包 | 实际菜单操作、过滤和异主零消耗测试 |
| 磁铁 | 默认关闭，4.5格立方范围，每10tick；尊重物主、拾取延迟、取消事件；事件后重新验证物品/范围/延迟；不吸储物袋 | 含事件取消与事件改变状态的真实拾取测试 |
| 野猪/王与掉落 | 使用五行伤害入口、原属性/生成位置约束；精血/毛皮有来源标记，环境死亡不赠玩家击杀收益 | ImportedCreaturesGameTests 5项：实际近战、击杀/环境、生成位置、精血药物/毛皮炼器及主人 |
| 药浴 | 4种不同主药各1株，保留NBT；1个四药批次只给1位符合资格玩家；200tick后走主修为收益/突破门槛；零收益不吞批次，拆除返剩余药 | ImportedContentGameTests实际交互、满修为/受阻、大小境界与200tick生命周期 |
